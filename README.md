# SpaceGame

A small 2D arcade space shooter built with TypeScript and GopherGfx.

This was my first complete game project. The player pilots a spaceship through a moving starfield while avoiding incoming UFOs and destroying them with laser fire.

## Play

**Play SpaceGame:**  
https://lethalretr0.github.io/SpaceGame/

## Gameplay

- Move and aim the ship with the mouse
- Click to fire lasers
- Destroy UFOs to earn points
- Avoid colliding with enemies
- The player starts with 3 lives
- Score and remaining lives are displayed on the HUD

## Features

- Mouse-controlled ship movement and aiming
- Scrolling starfield
- Homing enemies
- Projectile system
- Collision detection
- Enemy explosion animations
- Score system
- Lives system
- HUD
- Laser and player-damage sound effects
